## Как вставить в Word

### Способ 1: Прямая вставка SVG (Word 2016 и новее, MS 365)

1. Откройте `Диплом_Сбербанк_переводы.docx` в Word
2. Найдите место с подписью «[Рисунок X.X.X — ...]» — удалите эту строку
3. **Вставка → Изображения → Это устройство** → выберите нужный SVG-файл
4. Размер автоматически адаптируется к ширине страницы

### Способ 2: Конвертировать SVG в PNG (для старых версий Word)

Бесплатные онлайн-конвертеры:

- https://convertio.co/ru/svg-png/ — простой и быстрый
- https://cloudconvert.com/svg-to-png — настройка разрешения
- https://www.zamzar.com/ — без регистрации

**Рекомендации:**
- Установите разрешение **300 DPI** для печати качественной работы
- Размер: ширина **1500–1800 пикселей** (вписывается на страницу A4 без потери качества)

### Способ 3: Открыть в браузере и сделать скриншот

1. Перетащите SVG-файл в окно браузера (Chrome, Edge, Firefox)
2. Сделайте скриншот области с рисунком (Ctrl+Shift+S в Chrome)
3. Вставьте в Word

### Способ 4: Конвертация через Inkscape (бесплатно)

1. Скачайте [Inkscape](https://inkscape.org/ru/)
2. Откройте SVG → File → Export → PNG, выберите DPI и сохраните

## Подписи к рисункам в основном тексте

В тексте диплома уже есть подписи к каждому рисунку — они должны
располагаться **под рисунком, по центру, без отступа красной строки**,
например:

> Рисунок 2.1.1 – Динамика активов ПАО «Сбербанк» за 2022–2024 гг., млрд руб.

После вставки картинки удалите квадратный плейсхолдер
`[Рисунок 2.1.1 — ...]` и оставьте только саму картинку с подписью.

## Перерисовка / редактирование

SVG — это XML, и его можно открыть в любом текстовом редакторе.
Также для редактирования удобно использовать:

- [Inkscape](https://inkscape.org/) (бесплатный графический редактор)
- [draw.io](https://app.diagrams.net/) (веб-редактор с импортом SVG)
- [Figma](https://www.figma.com/) (профессиональный векторный редактор)

Если нужно перегенерировать с другими данными или цветами,
запустите скрипт `build_figures.py`:

```bash
python3 build_figures.py
```
